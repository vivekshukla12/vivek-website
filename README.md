# Vivek Shukla — Professional Website

A lightweight React + Vite personal website for Vivek Shukla, focused on Workday, HR technology leadership, digital transformation, integrations and analytics.

## Local development

```bash
npm install --legacy-peer-deps
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deployment

The current GitHub Pages workflow deploys only when changes are pushed to `main`. Work-in-progress design updates should be created on a separate branch and reviewed before merging to `main`.
